### 3b. Replace `bigint` with `Int64` — **`Int64`, never `UInt64`**

**[verified]** Nitrogen 0.37 hard-errors on raw `bigint`: `"Using a bigint without specifying signedness is deprecated! Use Int64 or UInt64 instead."` So this change is mandatory.

**[verified] Use `Int64` for every occurrence.** The mapping is:

| Spec type | Kotlin | Swift |
|---|---|---|
| `Int64` | `Long` | `Int64` |
| `UInt64` | `ULong` | `UInt64` |

The existing native code is uniformly signed — **zero** `ULong` in `Fs2Stream.kt`, and `ios/Fs2Stream.swift:186` explicitly clamps unsigned to signed (`fileLengthUInt > UInt64(Int64.max) ? Int64.max : Int64(fileLengthUInt)`). Choosing `UInt64` because sizes "can't be negative" would force `ULong` through 584 lines of Kotlin and the whole Swift stream file — Kotlin `ULong` has no implicit `Long` conversion, so every `file.length()`, `+=`, and comparison would need casts. **`Int64` is a drop-in requiring no native signature changes at all.**

**[verified]** `Int64`/`UInt64` are declared in `react-native-nitro-modules` as `bigint & { __tag?: never }` — plain aliases. So **`src/utils.ts` (`mapPropsWithBigInt`, `numberToBigInt`, `bigIntToNumber`) and `src/_filestream.ts` need no changes**; their `bigint` usage stays valid.

**Files:** Modify `src/nitro/Fs2Stream.nitro.ts`, `src/nitro/MediaStore.nitro.ts`

**Step 1: Import the type in both files**

**Step 2: Replace every `bigint` with `Int64`** — 13 occurrences in `Fs2Stream.nitro.ts` (lines 5, 6, 27, 28, 33, 34, 40, 52, 53, 58, 92) and 2 in `MediaStore.nitro.ts` (lines 16, 17).

## Task 6: Port #105 part 1 — `stat()` on `content://` URIs

**The bug:** `RNFSManager.kt:287` calls `getOriginalFilepath()` then `File(originalPath)`. For a `content://` URI whose provider exposes no `MediaStore.Images.Media.DATA` column, `getOriginalFilepath` returns the `content://` string unchanged and `File("content://…")` never exists → spurious `ENOENT`.

**Skip master's `Objects.equals` NPE fix** — [verified] `RNFSManager.kt:62` already uses `"content" == uri.scheme`, which is null-safe in Kotlin.

**[verified]** `IORejectionException(val code: String, message: String)` — the two-arg usage below is correct.

**Files:** Modify `android/src/main/java/com/margelo/nitro/fs2/RNFSManager.kt`

**Step 1: Add imports**

```kotlin

import android.provider.DocumentsContract
import android.provider.OpenableColumns
import java.io.FileNotFoundException
```

**Step 2: Add the content-URI stat path**

```kotlin
    private fun statContentUri(uri: Uri, filepath: String): NativeStatResult {
        val resolver = context.contentResolver
        var size = -1L
        var lastModified: Long? = null

        // Query without a projection — providers expose different column sets,
        // and asking for a column a provider lacks throws.
        resolver.query(uri, null, null, null, null)?.use { cursor ->
            if (cursor.moveToFirst()) {
                val sizeIdx = cursor.getColumnIndex(OpenableColumns.SIZE)
                if (sizeIdx != -1) size = cursor.getLong(sizeIdx)

                val lmIdx = cursor.getColumnIndex(DocumentsContract.Document.COLUMN_LAST_MODIFIED)
                if (lmIdx != -1) lastModified = cursor.getLong(lmIdx)
            }
        }

        // Fall back to the file descriptor when the provider reports no size.
        if (size < 0) {
            resolver.openAssetFileDescriptor(uri, "r")?.use { afd ->
                if (afd.length >= 0) size = afd.length
            }
        }

        // Existence check.
        try {
            resolver.openInputStream(uri)?.close()
                ?: throw IORejectionException("ENOENT", "File does not exist: $filepath")
        } catch (e: FileNotFoundException) {
            throw IORejectionException("ENOENT", "File does not exist: $filepath")
        }

        val mtimeSec = lastModified?.let { it / 1000 } ?: 0L

        return NativeStatResult(
            ctime = mtimeSec.toDouble(),
            mtime = mtimeSec.toDouble(),
            size = if (size >= 0) size.toDouble() else 0.0,
            type = StatResultType.FILE, // content URIs are files, never directories
            originalFilepath = filepath,
            mode = null,
        )
    }
```

```kotlin

```
